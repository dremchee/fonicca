Fonicca’s first public release brings local sample browsing, audio editing and processing into one desktop app.

## Highlights

- Browse your own audio libraries with folders, collections, colored tags, favorites, search and configurable columns.
- Preview audio with customizable waveforms, mouse zoom, level meters and playback synchronized to a project’s tempo and key.
- Analyze tempo, key and sound categories, and find similar sounds locally.
- Find duplicate files in grouped or flat views, choose the copy to keep, and hide or trash extra copies.
- Edit audio with selections, trimming, fades, gain, normalization, pitch/time processing, slicing and region export.
- Prepare multiple samples with batch processing, format conversion and filename templates.
- Separate tracks into stems, restore compressed music with Apollo, and export notes to MIDI with Basic Pitch. Optional models download when needed; audio processing stays on your computer.
- Check for signed app updates from Settings → About. Installation asks for confirmation and waits for editor windows and processing tasks to be closed or completed.

## Downloads

| Platform | Requirements | Installer |
| --- | --- | --- |
| macOS | Apple Silicon, macOS 13.4 or newer | `.dmg` |
| Windows | x64 | `-setup.exe` or `.msi` |
| Linux | Ubuntu 24.04 or compatible newer distribution, x64 | `.AppImage` or `.deb` |

Install this first version manually. Later published stable versions can be downloaded through the app updater on macOS, Windows and AppImage installations. Debian installations use the package manager.

`latest.json`, `.sig` files and the macOS `.app.tar.gz` archive support automatic updates; use the installers above for a normal installation. `SHA256SUMS.txt` contains checksums for the release assets.

## Notes

- macOS packages are not notarized and Windows installers are not code-signed. The updater’s cryptographic signatures are separate from operating-system code signing.
- Intel Macs are not supported in this release.
- Model quality and resource requirements vary. The app displays model-specific information and restrictions before processing.
- Stem separation and audio-to-MIDI work on mono/stereo files up to 10 minutes. Existing audio files are not replaced by these tools.

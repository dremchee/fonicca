This update brings the audio editor into the library and improves everyday playback and editing.

## Highlights

- Open the embedded audio editor by double-clicking a track. Resize or expand it without leaving the library.
- Preview tracks directly in their rows, with cached waveforms, playback progress and play/pause controls on hover.
- Save edits as a new WAV version by default. Keep working on that version, save to another location, or export a selection. Replacing an original WAV requires confirmation and creates a backup.
- Keep frequently used tools on the toolbar; tools that do not fit move into the overflow menu.
- Follow the playback cursor while zoomed in. Manual scrolling temporarily pauses automatic following.
- Adjust grid tempo from the editor footer and use a more compact track overview.
- Improve tooltip alignment and remove track-name tooltips from the library.

## Downloads

- **macOS:** Apple Silicon, macOS 13.4 or newer — `.dmg`.
- **Windows:** x64 — `-setup.exe` or `.msi`.
- **Linux:** Ubuntu 24.04 or a compatible newer distribution, x64 — `.AppImage` or `.deb`.

Existing installations can check for this update in Settings → About. Debian installations use the package manager. The macOS `.app.tar.gz`, signature files and `latest.json` are used by the updater; `SHA256SUMS.txt` provides asset checksums.

macOS packages are not notarized and Windows installers are not code-signed. Updater signatures are separate from operating-system code signing.

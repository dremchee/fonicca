# Organize with favorites, collections and tags {#overview}

These tools store assignments in the library. They can all refer to the same audio file.

| Tool | Use it for |
| --- | --- |
| **Favorites** | A shortlist you can open quickly across folders. |
| **Collections** | A named set of samples for a project or purpose. |
| **Tags** | Reusable labels such as `dusty` or `good for layering` that you can search and filter. |

## Mark a favorite {#favorites}

Click the star in the sample's row or press **F** with the library focused. Open **Favorites** in the sidebar to view the shortlist. Click the star again to remove a track from it.

## Build a collection {#collections}

1. Click **+** beside **Collections** and name the collection.
2. Select one or more samples. Right-click a selected row, choose **Add to collection** and select the collection. You can also create a collection from that menu.
3. Open the collection in the sidebar. To remove a track from it, right-click the track and choose **Remove from “…”**. The audio file stays in the library.

A collection can contain tracks from several sources. For example, collect audition candidates from several drum packs in a single project collection. Deleting a collection removes its grouping.

## Apply, filter and remove tags {#tags}

- **One sample.** Click **+** in its **Tags** cell. Select an existing tag, or type its name and choose **Create**.
- **Several samples.** Select the rows, then press **T** or choose **Add tag…** from their context menu. Choose a tag to apply it to the selection.
- **Filter by a tag.** Click a tag on a row or in the sidebar to see tracks with that tag.
- **Unassign a tag.** Open the row's tag picker and select the tag under **On this sample**.
- **Manage a tag.** Use the sidebar controls for the tag to rename it, change its color or delete it. Deleting it in the sidebar removes it from every sample that uses it.

Use [library data export](library-data.md) to take your favorites, tag assignments and collections to another installation.

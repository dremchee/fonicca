# Inspect and edit track information {#overview}

## Read audio properties {#inspect}

Play a sample and click **ⓘ** beside its name in the mini-player. Check the file type, channel count, sample rate or bit depth before choosing an export format. Peak level and integrated loudness are shown when available. The popover also shows embedded information such as the cover, artist and album.

## Edit title, artist or cover {#edit-metadata}

1. Choose **Edit** in the popover or **Edit info…** in the row's context menu. You can also press **I** with a track focused in the library.
2. Edit the title, artist, album, year or genre. Use **Choose image…** to set the front cover or **Remove cover** to clear artwork.
3. Save and reopen **Track info** to check the result. Fonicca writes these fields into the audio file when its format supports the edit. If saving fails, check file permissions and whether you can edit the file's metadata in that format.

Use [library tags](organize.md#tags) to label sounds for search and organization. Those assignments live in the library. Embedded title, artist and cover information can be read by other apps that support the file's tags.

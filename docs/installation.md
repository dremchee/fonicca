## Choose the interface language {#language}

Open **Settings → General → Language** and select **English** or **Русский**. The language menu on this site switches the documentation independently.

## First launch {#first-launch}

Open Fonicca and click **+** next to **Folders** to add a directory of audio files. The [user guide](user-guide.md#get-started) walks through indexing your library, listening to a track and exporting an excerpt.

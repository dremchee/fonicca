# SCNet XL IHF — сравнение 2026-10-25

Проверен оригинальный SCNet XL IHF из релиза MSST v1.0.15, без добавления
в приложение. На тех же трёх фрагментах XL улучшил средний SI-SDR каждого стема,
но прирост небольшой и не на каждой песне. Вокал улучшился на всех трёх.

| Средний SI-SDR, дБ | Spleeter | SCNet-large | SCNet XL IHF | XL − Large |
|---|---:|---:|---:|---:|
| Вокал | 8,03 | 13,10 | 13,65 | +0,55 |
| Ударные | 5,40 | 10,24 | 10,53 | +0,30 |
| Бас | 0,74 | 6,41 | 6,63 | +0,22 |
| Остальное | 3,47 | 7,25 | 7,98 | +0,73 |

По отдельным дорожкам XL лучше Large на 7 из 12; отличие ударных на Cristina
Vane всего −0,016 дБ. На Secretariat XL проиграл Large по ударным, басу и
остальному, выиграв по вокалу. Не следует трактовать небольшой тест как
универсальное превосходство XL.

## Источник и воспроизводимость

[Официальный релиз SCNet XL IHF](https://github.com/ZFTurbo/Music-Source-Separation-Training/releases/tag/v1.0.15).
Checkpoint `model_scnet_ep_36_sdr_10.0891.ckpt`, 214 063 778 байт (214 МБ / 204 МиБ),
SHA-256 `ac25975f0f5704f3d1a3c3c251505b7a0f417a22eafe82773440ee4f7e14b74f`.
Размер и хеш сверены с метаданными GitHub release asset.
Конфигурация `config_musdb18_scnet_xl_more_wide_v5.yaml` из того же релиза;
исходники `models/scnet/{scnet,separation,__init__}.py` взяты с тега v1.0.15.

PyTorch 2.14.1, CPU float32, inference_mode, четыре потока; исходный класс SCNet,
53 466 800 параметров. Веса загружены с `weights_only=True` и `strict=True`,
без пропуска слоёв и подгонки форм. Из YAML безопасно прочитаны только разделы
`audio` и `model`, без выполнения Python-тегов в настройках аугментаций.
Нормализация входа выключена согласно training/inference.normalize в конфигурации
автора. В нашей SCNet-large нормализация включена согласно её контракту.

Окно 485 100 отсчётов (11 с), шаг 2,75 с, края 1,1 с. Для короткого фрагмента,
занимающего больше половины окна, отражённое дополнение до 11 с; одна обработка
на фрагмент, как в предыдущем сравнении Large. Выходы обрезаны до исходной длины.
Нельзя напрямую переносить показатели на другую схему окон или весь датасет.

Материал: те же официальные MUSDB18 test previews — Cristina Vane — So Easy,
Louis Cressy Band — Good Time, Secretariat — Borderline. Каждый 6,8034467 с,
44,1 кГц, стерео. Метод SI-SDR описан в [сравнении SCNet-large](scnet-comparison.md).
Это не BSSEval SDR из таблицы авторов. Все выходы имеют ровно 300 032 стереокадра,
конечные значения, WAV float32. Максимальный абсолютный отсчёт среди трёх моделей
и эталонов — 0,5872; отсчётов за полной шкалой нет. Громкость между моделями не
подгонялась. Аудио и веса остаются вне Git.

## Скорость и память

M1 Pro, 16 ГБ, CPU. Загрузка модели 0,36 с. XL IHF обработал три фрагмента за
34,88 / 41,50 / 41,99 с. Пиковый RSS процесса — 4,63 ГБ. Время и память включают
тестовую среду PyTorch, не являются измерением будущей ONNX-интеграции.
На компьютере выполнялись и другие задачи.

Предыдущий SCNet-large запускался через ONNX Runtime с хранимыми INT8-весами,
вычислениями float32: 11,36–13,82 с на те же фрагменты, с загрузкой и записью.
У XL исходный FP32 checkpoint. Из-за разных сред и условий эти числа служат
ориентиром для текущих конфигураций, а не чистым рейтингом архитектур.

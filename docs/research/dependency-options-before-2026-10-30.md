### Разделение на стемы

Код почти везде MIT, **проблема — веса**: большинство моделей обучены на MUSDB18 (треки под CC BY-NC-SA) или имеют неясное происхождение.

| Модель | Код | Веса | Статус | Комментарий |
|---|---|---|---|---|
| Spleeter (Deezer) 2/4/5 stems | MIT | Статья авторов указывает MIT для весов; README и issue #898 оставляют неоднозначность | ⚠️ | Рабочий 4-stem прототип; перед коммерческим релизом проверить условия весов. См. [исследование](stem-separation.md) |
| Mel-Band RoFormer (Kim Vocal 2) | MIT | Заявлен MIT (перелицензирован автором в 2026), происхождение данных не документировано | ⚠️ | Лучшее качество вокала. Проверить оригинальную карточку KimberleyJSN/melbandroformer, юр. ревью |
| ZFTurbo MSS-Training чекпоинты | MIT | MIT по LICENSE репо, но файл добавлен позже ранних релизов | ⚠️ | Поштучная проверка каждого чекпоинта |
| BS-RoFormer (lucidrains и др.) | MIT | Зависит от чекпоинта, часто «unknown» | ⚠️/❌ | — |
| Demucs / HTDemucs (Meta) | MIT | «Только для научных целей» (автор, issue #327) | ❌ | Включая ONNX/MLX-конвертации |
| Open-Unmix umxhq / umxl | MIT | Обучены на MUSDB18 / доп. данных | ⚠️/❌ | Риск из-за NC-датасета |

**Решение:** модели — подключаемые плагины, скачиваются отдельно. В разработке — Spleeter 4-stems через закреплённые ONNX-артефакты; веса скачиваются отдельно. До коммерческого релиза проверить неоднозначность условий весов. RoFormer-вокал — после юр. проверки. Для топового качества в будущем — своё обучение на лицензированных данных или платный API (AudioShake, Music.AI и т. п.).

## Итог по изменениям в плане

- Убрать aubio и Essentia → stratum-dsp (+ beat-this).
- chromaprint → rusty-chromaprint.
- Time-stretch: signalsmith-stretch подтверждён.
- CLAP: только аудио-энкодер laion/clap-htsat-unfused (ONNX int8 от Xenova, 34 МБ), Apache-2.0; текстовый энкодер не нужен.
- Стемы: Spleeter по умолчанию, Demucs не использовать.
- Waveform: wavesurfer.js (BSD), не peaks.js.

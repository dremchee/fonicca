# Установка Fonicca

## Загрузка и системные требования {#downloads}

Скачайте установщик из [GitHub Releases](https://github.com/dremchee/fonicca/releases).

| Система | Требования | Пакет |
| --- | --- | --- |
| macOS | Apple Silicon, macOS 13.4 или новее | `.dmg` |
| Windows | x64 | `-setup.exe` или `.msi` |
| Linux | Ubuntu 24.04 или совместимый более новый дистрибутив, x64 | `.AppImage` или `.deb` |

Сборка macOS рассчитана на Apple Silicon. Установщики macOS не проходят нотарификацию Apple, а установщики Windows поставляются без подписи издателя.

Первую версию установите вручную. На macOS, Windows и в версии AppImage проверять стабильные обновления можно в разделе **Настройки → О программе**. Пакет `.deb` обновляется через пакетный менеджер.

## Язык интерфейса {#language}

Откройте **Настройки → Основные → Язык** и выберите **Русский** или **English**. Язык документации меняется отдельно через меню на сайте.

## Первый запуск {#first-launch}

Откройте Fonicca и нажмите **+** рядом с разделом **Папки**, чтобы добавить каталог с аудио. В [руководстве](user-guide.md#get-started) описано, как дождаться индексации, прослушать трек и экспортировать фрагмент.

# Преобразование аудио в MIDI через Basic Pitch {#overview}

Basic Pitch распознаёт ноты и записывает в MIDI время и силу их нажатия. Начните с отчётливой партии одного мелодического инструмента, например баса, пианино или гитары. MIDI содержит ноты для воспроизведения инструментом. Изгибы высоты тона (pitch bend) в результат не входят.

## Выберите аудио для распознавания {#choose-input}

| Откуда открыть команду | Что будет распознано |
| --- | --- |
| Контекстное меню трека → **Обработка → Экспорт MIDI…** | Весь исходный аудиофайл. |
| Редактор → **Экспорт MIDI…** при активном выделении | Выделенный фрагмент текущей правки, включая изменения в редакторе. |
| Редактор → **Экспорт MIDI…** без выделения | Вся текущая правка, включая несохранённые изменения. |

Basic Pitch принимает моно или стерео до 10 минут. Для части длинной записи сначала выделите нужный отрывок в редакторе, затем откройте окно экспорта.

## Экспортируйте MIDI и проверьте его в DAW {#export-midi}

1. Проверьте, что окно показывает нужный источник. При первом запуске нажмите **Скачать модель и экспортировать…**. В остальных случаях выберите **Экспорт MIDI…**.
2. Укажите, куда сохранить MIDI-файл. Распознавание выполняется локально. После завершения видно, сколько нот было найдено.
3. Импортируйте MIDI на дорожку виртуального инструмента в DAW. Сравните её с аудиозаписью и при необходимости скорректируйте высоту или длину нот.

Если распознаётся мало нот, попробуйте более короткий и чистый отрывок или отдельную партию. Например, [выделите бас в отдельный стем](stems.md) и распознайте ноты из этого файла. Если модель не загрузилась, проверьте её состояние в **Настройки → Анализ → Модели**.

# Петли и нарезка аудио {#overview}

Петля повторяет один диапазон. Маркеры нарезки делят запись на регионы, которые можно отдельно прослушать или сохранить.

## Прослушайте и сохраните петлю {#loop-points}

1. Откройте трек в редакторе и выделите фрагмент. Уточните границы с помощью [сетки и масштаба](editor.md#grid-and-zoom).
2. Включите **Луп** и запустите воспроизведение в редакторе. Прослушайте переход с конца на начало и при необходимости измените выделение.
3. Нажмите **Точки лупа** или **Shift + L**, чтобы сохранить границы по выделению. Флажки петли можно перетащить на линейке. Чтобы убрать точки, снимите выделение и примените ту же команду.
4. [Сохраните результат в WAV](export.md#formats), чтобы записать эти точки в файл. Сможет ли сэмплер или DAW их использовать, зависит от поддержки метаданных WAV.

Переключатель **Луп** управляет повтором при прослушивании в редакторе. Для записи границ в экспортируемый файл используйте **Точки лупа**.

## Расставьте маркеры вручную {#manual-slices}

Дважды щёлкните по линейке или нажмите **M**, чтобы поставить маркер у курсора. Если есть выделение, **M** ставит маркеры на обеих границах. Чтобы изменить границу, перетащите флажок. Удалить маркер можно через его контекстное меню. Щелчок по региону на линейке выделяет его. Клавиши **1–9** и **Shift + 1–9** воспроизводят регионы 1–18.

## Найдите границы автоматически {#automatic-slices}

1. Выделите нужный фрагмент или снимите выделение, чтобы обработать весь файл. Откройте **Нарезка**.
2. Выберите режим по материалу.

   | Режим | Что настроить |
   | --- | --- |
   | **Сетка** | Задайте BPM в редакторе и выберите деление по долям или тактам. Подходит для нарезки лупа на равные отрезки. |
   | **Удары** | Укажите чувствительность и минимальную длину слайса. Подходит для разделения ударных по атакам. |
   | **Тишина** | Задайте порог тишины и минимальную длину паузы. Подходит для разметки звуков, записанных с паузами. |

3. Проверьте найденные регионы и примените разметку. Уточните границы перетаскиванием флажков и прослушайте каждый регион перед экспортом.

## Сохраните отдельные регионы {#save-regions}

Чтобы пропустить регион, щёлкните по нему на линейке с **Option / Alt**. Вернуть его в экспорт можно тем же жестом или через контекстное меню региона. В меню сохранения выберите **Сохранить регионы**. Fonicca запишет включённые регионы в пронумерованные WAV в новой папке нарезки рядом с текущим треком. В редакторе останется открытой полная запись. Если папка результата находится вне библиотеки, откройте файлы через файловый менеджер.

# Добавление папок и работа со списком {#overview}

Fonicca собирает библиотеку из ваших папок. Приложение обращается к аудио по исходным путям. С теми же файлами можно работать в DAW и файловом менеджере.

## Добавьте папку с аудио {#add-folders}

1. Нажмите **+** рядом с разделом **Папки** или откройте **Настройки → Библиотека → Добавить папки…**.
2. Выберите папку с аудио. Fonicca просканирует её вместе с подпапками. Повторите это для других наборов семплов, экспортов проектов или записей.
3. Откройте папку на боковой панели и начните [прослушивать семплы](playback.md). Треки появляются по мере индексации. Темп, тональность, громкость и категория могут заполниться позже, в ходе [анализа](search.md#analysis).

Fonicca читает WAV, AIFF, FLAC, MP3, OGG, M4A и CAF. В контейнере вроде M4A могут использоваться разные кодеки, поэтому возможность открыть файл зависит и от его содержимого.

## Переходите между папками и выделяйте строки {#navigate}

Разверните источник, чтобы увидеть подпапки. Путь над таблицей позволяет вернуться на один или несколько уровней вверх. **Все семплы** показывает треки из всех источников. В разделе папки видны и треки из её подпапок.

| Действие | Как выполнить |
| --- | --- |
| Выбрать и прослушать трек | Щёлкните по строке. Двойной щелчок откроет редактор. |
| Выделить диапазон | Удерживайте **Shift** и щёлкните по другой строке или используйте **Shift** и стрелки. |
| Добавить или исключить отдельную строку | Щёлкните по ней с **Command** на macOS или с **Ctrl** на Windows и Linux. |
| Выделить все результаты в текущем разделе | Нажмите **Command/Ctrl + A**, когда библиотека в фокусе. |

Выделение пригодится, чтобы [разметить тегами](organize.md#tags), [перетащить](playback.md#daw) или [обработать](batch.md) сразу несколько файлов. Для групповой команды вызывайте контекстное меню на одной из выделенных строк.

## Настройте таблицу {#columns}

Щёлкните по заголовку, чтобы сортировать по полю. Перетащите границу между заголовками, чтобы изменить ширину. В меню **Колонки** можно показать или скрыть поля и **Сбросить ширину колонок**. Включите колонку **Директория**, если в разных источниках встречаются файлы с одинаковым именем.

## Обновите или уберите папку {#refresh}

- Включите **Настройки → Библиотека → Следить за изменениями в папках**, чтобы изменения на диске отражались в библиотеке автоматически.
- Для ручного обновления откройте контекстное меню источника и выберите **Пересканировать**. Внешний диск сначала подключите по прежнему пути.
- Команда **Убрать из библиотеки** удаляет источник из индекса. Файлы остаются на диске. Чтобы вернуть источник, добавьте папку заново. Отдельно скрытый трек можно вернуть через [Скрытые файлы](duplicates.md#restore).

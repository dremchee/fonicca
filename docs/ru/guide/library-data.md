# Экспорт и перенос данных библиотеки {#overview}

Экспорт сохраняет избранное, названия и назначения тегов, а также коллекции в JSON. Для переезда на другой компьютер перенесите этот JSON и исходные папки с аудио. Для тем предусмотрен [отдельный экспорт](settings.md#themes).

## Экспортируйте назначения {#export-data}

1. Откройте **Настройки → Библиотека → Ваши данные → Экспорт…**.
2. Выберите, куда сохранить JSON. Храните его вместе с резервной копией аудио, чтобы он был доступен при настройке другой установки.

В JSON записаны пути к файлам, по которым Fonicca сопоставляет треки. Учитывайте это, если передаёте экспорт другому человеку.

## Импортируйте данные на другом компьютере {#import-data}

1. Скопируйте папки с аудио. В Fonicca [добавьте папки](library.md#add-folders) и дождитесь окончания сканирования.
2. Откройте **Настройки → Библиотека → Ваши данные → Импорт…** и выберите JSON. Fonicca сначала ищет файл по сохранённому пути. Если путь не совпал и в экспорте есть отпечаток файла, приложение пробует сопоставить файлы по содержимому и размеру.
3. Проверьте отчёт импорта и откройте знакомую коллекцию или тег. Импорт объединяет назначения с текущей библиотекой. Повторный импорт того же файла их не дублирует.

Если часть файлов не найдена, убедитесь, что они находятся на диске и просканированы. Добавьте или пересканируйте источник и повторите импорт. Изменившееся аудио или отсутствие отпечатка может помешать сопоставлению по новому пути.

## Найдите локальные файлы Fonicca {#storage}

В **Настройки → О программе → Хранилище** видны пути к базе библиотеки, файлу настроек и папке моделей. Это отдельные файлы приложения. Чтобы повторно установить модель на новом компьютере, откройте **Настройки → Анализ → Модели**.

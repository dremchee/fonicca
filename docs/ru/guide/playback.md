# Прослушивание семплов и передача в DAW {#overview}

## Управляйте мини-плеером {#mini-player}

Щёлкните по строке, чтобы прослушать семпл в плавающем мини-плеере. Используйте его кнопки для воспроизведения, паузы, остановки или перехода к соседнему треку. Щёлкните по полосе воспроизведения или перетащите ползунок для перемотки. Чтобы сменить положение плеера, потяните за его панель. Когда сама панель в фокусе, панель можно сдвигать стрелками, а **Home** возвращает её вниз.

Для быстрого отбора звуков перейдите по списку стрелками вверх и вниз. Пункт **Настройки → Аудио → Автовоспроизведение** определяет, будет ли при этом запускаться звук. Когда библиотека в фокусе, **Пробел** запускает или приостанавливает выбранный трек, а **Esc** останавливает прослушивание. В редакторе своё управление воспроизведением.

## Выберите, с какого места играет строка {#click-behavior}

Откройте **Настройки → Аудио → Клик по треку**.

| Режим | Что делает щелчок |
| --- | --- |
| **С места клика** | Запускает трек или перематывает его к месту щелчка по загруженной волне. |
| **Всегда с начала** | Каждый щелчок запускает трек с 0:00. |
| **Новый трек — с начала** | Новый выбранный трек играет с 0:00. Повторный щелчок по волне перематывает к нужной точке. |
| **Option / Alt + клик — с позиции** | Обычный щелчок запускает трек с 0:00. Щелчок по загруженной волне с **Option / Alt** запускает его с выбранной точки. |

Пока волна загружается, перематывайте через полосу мини-плеера. Характеристики и результаты анализа трека доступны в [информации о треке](track-info.md).

## Настройте выход и громкость {#audio-output}

Откройте **Настройки → Аудио → Устройство вывода** и выберите системный выход или аудиоинтерфейс. При смене выхода воспроизведение останавливается. Запустите его снова, чтобы проверить новое устройство. Если устройство пропало после переподключения, нажмите **Обновить устройства**. Если воспроизведение идёт без звука, проверьте переключатель звука и громкость мини-плеера.

## Перетащите файл в DAW {#daw}

1. Откройте проект в DAW, которая принимает перетаскиваемые файлы.
2. Перетащите строку семпла на дорожку или в сэмплер. Для переноса нескольких треков сначала [выделите строки](library.md#navigate), затем потяните за одну из них.
3. Проверьте импортированные клипы и при необходимости настройте их уровень в DAW.

При перетаскивании передаются существующие файлы с их сохранёнными уровнями. Громкость мини-плеера действует при прослушивании в Fonicca. Чтобы перенести обработанное аудио, сначала [сохраните результат](export.md), затем перетащите этот файл.

# Сохранение и экспорт аудио {#overview}

Откройте меню **Сохранить** в редакторе и выберите команду по нужному результату.

## Выберите, что сохранить {#commands}

| Команда | Результат |
| --- | --- |
| **Сохранить** | При первом сохранении выберите новый файл. Позже команда обновляет текущий файл сохранения в его формате и с последней частотой экспорта. |
| **Сохранить как…** | Записывает весь результат в выбранный файл. Этот файл становится текущим для дальнейших сохранений. |
| **Сохранить выделение…** | Записывает выделенный диапазон в новый файл. Текущий сеанс и его файл сохранения остаются прежними. |
| **Сохранить регионы** | Создаёт отдельный WAV для каждого включённого региона в папке рядом с текущим треком. Подробнее об [экспорте нарезки](loops-slices.md#save-regions). |
| **Заменить оригинал…** | Записывает всю правку поверх исходного WAV, когда команда доступна. Перед подтверждением проверьте путь. Fonicca создаст резервную копию предыдущего аудио. |

**Сохранить** доступно, когда есть изменения. Для команды **Сохранить выделение…** нужно сначала выделить диапазон. Чтобы сменить формат или частоту текущего файла сохранения, используйте **Сохранить как…**.

## Выберите формат и частоту {#formats}

| Формат | Что записывает Fonicca |
| --- | --- |
| WAV | Несжатое аудио с исходной разрядностью, когда она поддерживается. Сохраняет точки петли и маркеры нарезки. |
| FLAC | Сжатие без потерь, PCM 24 бит. |
| AIFF | Несжатый PCM 24 бит. |
| M4A | Apple Lossless (ALAC), PCM 16 бит. |
| CAF | Несжатый PCM с плавающей точкой, 32 бита. |
| MP3 | Сжатие с потерями. Доступные частоты зависят от кодировщика. |
| Ogg Vorbis | Сжатие с потерями и переменным битрейтом. |

В окне **Сохранить аудио** выберите формат и **Частоту дискретизации**, затем нажмите **Продолжить**, чтобы указать имя и папку файла. Вариант **Как в исходнике** сохраняет текущую частоту, если формат её поддерживает. Для переноса [точек петли и маркеров нарезки](loops-slices.md) в другую программу выберите WAV.

## Экспортируйте короткий клип {#export-selection}

1. Выделите нужный фрагмент в редакторе. Нажмите **Пробел** и проверьте начало и конец выделения.
2. Выберите **Сохранить выделение…**, задайте формат, частоту дискретизации и отдельное имя для клипа.
3. Откройте полученный файл в плеере или [перетащите его в DAW](playback.md#daw). Если сохранили его вне индексируемых папок, откройте его в файловом менеджере или [добавьте папку](library.md#add-folders) в Fonicca.

Если Fonicca сообщит, что аудио записано, но библиотеку обновить не удалось, откройте папку результата в файловом менеджере. Если папка входит в индексируемый источник, попробуйте пересканировать этот источник.

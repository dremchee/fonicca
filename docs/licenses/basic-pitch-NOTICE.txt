Fonicca adapts windowing, onset inference, polyphonic note decoding and time
alignment from basic_pitch/inference.py and basic_pitch/note_creation.py.
The audio decoder/resampler, bounded ONNX runner, MIDI file writer and desktop
integration are implemented in Rust. This version exports note on/off events
and velocity; pitch-bend and contour export are not included.

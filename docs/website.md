# Сайт Fonicca — отложенная идея

Статус на 2026-10-27: разработка сайта отложена по решению пользователя. Исходники лендинга, браузерного демо, их сборки и зависимости удалены из рабочего проекта. Здесь сохранены концепция и заметки для возможного возвращения к задаче; готовой реализации в репозитории больше нет.

## Назначение

Показать возможности Fonicca и привести пользователя к загрузке приложения с GitHub Releases. Основной акцент — локальная библиотека звуков, аудиоредактор, стемы и MIDI без загрузки пользовательского аудио в облако.

## Концепция страницы

- Русский и английский языки.
- Первый экран: «Твой звук. Твой ритм.» / «Your sound. Your rhythm.» и пояснение «Находи, редактируй и разделяй звук. В одном приложении.»
- Ссылки на загрузки macOS, Windows и Linux.
- Демонстрация приложения с переключением «Библиотека / Редактор / Стемы».
- Три сценария: найти звук через папки, теги и фильтры; отредактировать фрагмент; разделить трек на стемы или получить MIDI.
- Отдельный блок о локальной обработке и хранении файлов.
- Загрузки, FAQ и ссылки на GitHub внизу страницы.

Визуальное направление: крупная типографика Inter, фиолетовый акцент, скругления в характере приложения, адаптивная композиция и крупная демонстрация интерфейса. Это направление для дальнейшей проработки, а не утверждённый дизайн.

## Подход к интерактивному демо

В удалённом прототипе использовались Astro для статического лендинга и отдельная браузерная сборка Vue/Vite. Демо подключало настоящие компоненты приложения и редактора из `src/`, не копируя их. Нативные операции заменялись моками и браузерными адаптерами.

Планируемые возможности демо:

- Поиск, фильтры, плеер, редактор и раскрытие стемов на демонстрационных данных.
- Декодирование демонстрационного аудио и построение волны в браузере.
- Синтетические сценарии редактирования и обработки; без доступа к пользовательским файлам, нативному бэкенду и настоящим моделям.
- Изменения только в памяти, со сбросом при перезагрузке.
- Встраивание в страницу через iframe `/demo/` и проверяемый протокол сообщений в пределах одного origin.

Для аудио прототипа использовались три официальных HQ MP3-превью holizna, заявленные как CC0 1.0: [Afterimage](https://freesound.org/people/holizna/sounds/866733/), [Driftglass](https://freesound.org/people/holizna/sounds/866736/), [Lo-Fi Drums](https://freesound.org/people/holizna/sounds/629134/). Сами файлы удалены вместе с демо; перед повторным использованием проверить источники и условия заново.

## Если возвращаться к сайту

- [ ] Сначала согласовать необходимость сайта и объём: статическая страница со скриншотами или интерактивное демо.
- [ ] Сверить тексты и ссылки с актуальными релизами; в старом прототипе оставались формулировки «первый релиз скоро».
- [ ] Использовать актуальные скриншоты из `docs/screenshots/`.
- [ ] Если демо действительно нужно, сохранить общие компоненты с приложением, явно обозначить имитацию ИИ-обработки и проверить поведение без нативных API.
- [ ] Проверить доступность, мобильную версию, размер загрузок и права на демонстрационные материалы.
- [ ] Публикацию и хостинг планировать отдельно после согласования результата.
